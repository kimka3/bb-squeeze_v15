# AATR-L2X-S720 에 TP15 · SMA240 청산을 넣으면? (검증 결과)

`python3 research/aatr_long/run_study.py` 로 재현 (약 15초). 결과 CSV 는 `results/`.

## 조건
- 데이터: 레포의 Binance USD-M 선물 4H (`data/raw`), 평가 2021-03-08 ~ 2026-08-31 (SMA720 예열 이후). 11개 종목.
- Pine 규칙 그대로: 신호 다음 봉 시가 체결, 자산 200%(수량 = 2×자산/신호봉 종가), 수수료 0.1%/편도, 슬리피지 0, 펀딩 미반영(별도 표).
- TP15: 진입가 +15% 가격 지정가. 체결 봉 종가에 주문이 걸려 다음 봉부터 유효, 고가 도달 시 체결.
- 변형: A 원본(S720 청산) / B +TP15 / C 청산선을 SMA240 으로 교체 / D TP15+S240 / E SMA240 **또는** SMA720 하향 교차 / F TP15+E.
- TradingView 와의 체결 일치는 검증하지 못했다 (TV 실행 불가).

|---|---|---|---|---|---|

## 판정
1. **TP15 는 기각.** BTC 에서 CAGR 이 거의 반으로 줄고 MAR 도 나빠진다. 줄어드는 MDD 보다 잘려나가는 수익이 더 크다.
   TP×청산SMA 격자(`grid_tp_exit.csv`)에서 BTC 성과는 TP 를 높일수록 대체로 좋아지고, TP15 는 아래쪽에 있다.
   이 전략의 수익은 소수의 대형 추세에서 나온다 (원본 최대 1건이 순이익의 57%).
2. **SMA240 으로 '교체'(C·D)는 기각.** 진입할 때 이미 종가가 SMA240 아래면 하향 교차가 나오지 않아 손실이 계속 커진다.
   BTC 2026-05-30 진입 건은 -31%(자산 기준). 알트 4개 종목에서는 자산이 0 아래로 내려갔다(MDD ≤ -100%).
3. **'SMA240 또는 SMA720' 청산(E)은 조건부 유망.** BTC 에서 CAGR·MDD·MAR 모두 좋아지고, 11개 중 9개 종목에서 MAR 이 개선됐다.
   다만 BTC 개선분은 2021~2023 에 몰려 있다 (2024~2026-08 CAGR: A 23% vs E 20%). 거래 수도 적다.
4. 원본을 포함한 모든 변형이 종목 중앙값으로는 손실이다 (CAGR -2% ~ -22%). 이 표본에서 전략이 통한 곳은 BTC 이고, SOL·AVAX·ETH 는 일부만 통했다.

## 정정: TradingView 2020-01 시작 결과에서 E안이 원본에 크게 진다
사용자가 TradingView 에서 BTCUSDT 바이낸스 현물 4H 로 돌린 결과 (2020-01-01 ~ 2026-10-26, 딥 백테스팅):

| | 총수익 | MDD | 거래 | 승률 | PF |
|---|---|---|---|---|---|
| 원본 S720 | +11,926% | 39.1% | 30 | 26.7% | 2.12 |
| E안 S240 또는 S720 | +2,019% | 34.7% | 41 | 36.6% | 2.53 |

- 원인: 2020-09 ~ 2021-05 상승장. 위 검증은 레포 데이터가 2020-11 부터라서 이 구간이 빠져 있었다.
- Alpha Vantage BTC 일봉으로 근사 검증했다 (SMA720→SMA120D, SMA240→SMA40D, ATR 은 4H/일봉 비율 0.413 으로 보정).
  - 원본은 2020-09-25 (약 10.7k) 에 진입해 2021-05-14 (약 49.7k) 까지 보유했다.
  - E안은 2020-10-07 SMA40D 이탈로 청산됐다. 이후 가격이 진입선 위에 머물러 상향 교차가 다시 나오지 않았고, 상승장 전체를 놓쳤다.
  - 일봉 근사 총수익: 원본 +6,443%, E +654%. 방향은 TradingView 결과와 같다.
- 구조적 결함: 빠른 청산 뒤 가격이 진입선 위에 있으면 재진입할 수 없다.
  'SMA240 재돌파 시 재진입' 규칙을 붙여 보면, 일봉 2020~ 에서는 원본보다 나았지만 4H 2021-03~ 에서는 원본보다 나빴다 (거래 100회, 잦은 들락날락). 일관성이 없어 채택하지 않는다.
- 판정 변경: E안은 '조건부 유망'에서 **기각**으로 바꾼다. 원본 S720 을 유지한다.

## 원본(S720) vs 바이앤홀드 (`compare_bh_original.py`)
- TradingView 2020-01-01 ~ 2026-10-26: 원본 +11,926% (CAGR 약 102%, MDD 39.1%). 같은 기간 BTC 보유는 약 +1,000% (CAGR 약 43%, MDD 약 -77%, Alpha Vantage 일봉 기준).
- 4H 레포 2021-03 ~ 2026-08: 원본 1x CAGR 31% / MDD -31%, 원본 2x 53% / -51%. BH 1x 는 8% / -77%. BH 2x 는 2022년에 청산됐다.
- 일봉 근사로 2018 ~ 2025 사이 분기마다 시작점을 바꿔 29번 계산했다. 원본 2x 는 27번, 원본 1x 는 23번 BH 1x 보다 CAGR 이 높았다.
  진 구간은 2020-10, 2024-01 처럼 상승장 중간에 시작한 경우다. 이미 진입선 위에 있어 새 교차를 기다리는 동안 상승분을 놓친다.
- 연도별로 보면 원본의 우위는 하락장 회피에서 나온다 (2018: 원본 1x -10% vs BH -73%, 2022: -12% vs -64%).
  강한 상승장에서는 원본 1x 가 BH 에 진다 (2020, 2023, 2024).

## ETH: 원본 vs 바이앤홀드 (`compare_bh_original.py <eth_daily.csv> ETHUSDT`)
- 4H 레포 2021-03 ~ 2026-08: 원본 2x CAGR 18% / MDD -73%. 펀딩을 반영하면 CAGR 8% 로 BH 1x (7%, MDD -81%) 와 비슷하다. 원본 1x 는 14% / -51%.

  - 2020-03-12 코로나 폭락에서 2x 포지션이 하루에 약 -36% 가격 갭을 맞았다. 자산이 88k 에서 25k 로 줄었다.
    일봉 근사라서 4H 에서는 손실이 더 작을 수 있다 (확인 안 됨).

### 정정: ETH TradingView 결과가 일봉 근사와 크게 다르다
사용자가 TradingView 에서 ETHUSDT 바이낸스 현물 4H 로 돌린 결과 (2017-08-17 ~ 2026-10-26): 원본 2x **+4,744%**, MDD 59.3%, 거래 38회, 승률 29%, PF 1.82.
- 같은 기간 BH 1x 는 약 +670% 다 (302 → 약 2,320). CAGR 은 원본 약 52%, BH 약 25%. BH 의 MDD 는 약 -94% (2018).
- 일봉 근사로 2017-12-15 부터 계산하면 (TV 의 SMA720 예열 이후와 비슷한 시점) 원본 2x 는 +505%, MDD -90% 다. TV 와 약 8배 차이가 난다.
  BTC 에서는 근사와 TV 의 차이가 약 1.9배였다. 변동성이 큰 ETH 에서는 일봉 근사가 쓸 수 없을 만큼 틀린다.
  추측: 급락 때 4H 는 몇 시간 안에 청산하지만, 일봉은 종가와 다음 날 시가까지 기다린다 (2020-03-12 등).
- 판정 변경: 'ETH 우위 약함 · 2x 비권장' 은 일봉 근사에 기댄 판단이었으므로 철회한다.
  TV 4H 기준으로 ETH 도 2017-08 시작에서는 BH 를 크게 앞선다. 다만 2020-01 시작처럼 BH 에 유리한 구간에서도 그런지는 TV 로 확인되지 않았다.

## ETH 개선 방향 검토 (`improve_study.py`, 4H 레포 2021-03 ~ 2026-08)
| 방향 | ETH 결과 | BTC · 11종목 | 판정 |
|---|---|---|---|
| ① 레버리지 1x | CAGR 18%→14%, MDD -73%→-51%. 펀딩 후 CAGR 은 1x~2x 모두 8% | BTC 는 MAR 이 거의 같다 (0.99~1.03) | **채택** (ETH 는 1x, 현물이면 펀딩 0) |
| ② 진입 ATR 배수 (상승 시 k_up) 축소 | k_up 0.75→0.25: CAGR 18%→29%, MAR 0.24→0.38. 0~0.25 구간이 평탄하고, 전반·후반 모두 개선. 전반 최적값의 후반 순위는 4/35 | BTC 는 무차이 (k_up 은 거의 영향 없음). 11종 중앙값도 개선 없음 | **조건부** (ETH 전용, TV 2017~ 로 확인 필요) |
| ③ 진입가 기준 고정 % 손절 | 2~4% 손절은 CAGR 이 마이너스로 바뀐다. 5~15% 도 원본보다 나쁘다 | BTC 도 모든 폭에서 악화 | **기각** |
- ③ 이 실패하는 이유: 손절이 SMA720 보다 위에 있으면 추세 초입의 흔들림에 털린다. 그리고 재진입은 진입선을 새로 상향 교차해야만 가능하다.
- ② 가 ETH 에서 통하는 이유 (추측): ETH 는 ATR 이 커서 진입선이 SMA 에서 멀다. k_up 을 낮추면 일찍 들어가고 손절 폭(진입가 - SMA)도 줄어든다.
  다만 BTC 와 다른 종목에서는 효과가 없어, ETH 표본 하나에 맞춘 결과일 가능성이 있다.
- k_dn (하락·보합 시 배수) 은 ETH·BTC 모두 영향이 작다.
