# AATR-L2X-S720 에 TP15 · SMA240 청산을 넣으면? (검증 결과)

`python3 research/aatr_long/run_study.py` 로 재현 (약 15초). 결과 CSV 는 `results/`.

## 조건
- 데이터: 레포의 Binance USD-M 선물 4H (`data/raw`), 평가 2021-03-08 ~ 2026-08-31 (SMA720 예열 이후). 11개 종목.
- Pine 규칙 그대로: 신호 다음 봉 시가 체결, 자산 200%(수량 = 2×자산/신호봉 종가), 수수료 0.1%/편도, 슬리피지 0, 펀딩 미반영(별도 표).
- TP15: 진입가 +15% 가격 지정가. 체결 봉 종가에 주문이 걸려 다음 봉부터 유효, 고가 도달 시 체결.
- 변형: A 원본(S720 청산) / B +TP15 / C 청산선을 SMA240 으로 교체 / D TP15+S240 / E SMA240 **또는** SMA720 하향 교차 / F TP15+E.
- TradingView 와의 체결 일치는 검증하지 못했다 (TV 실행 불가).

## 판정
1. **TP15 는 기각.** BTC 에서 CAGR 이 거의 반으로 줄고 MAR 도 나빠진다. 줄어드는 MDD 보다 잘려나가는 수익이 더 크다.
   TP×청산SMA 격자(`grid_tp_exit.csv`)에서 BTC 성과는 TP 를 높일수록 대체로 좋아지고, TP15 는 아래쪽에 있다.
   이 전략의 수익은 소수의 대형 추세에서 나온다 (원본 최대 1건이 순이익의 57%).
2. **SMA240 으로 '교체'(C·D)는 기각.** 진입할 때 이미 종가가 SMA240 아래면 하향 교차가 나오지 않아 손실이 계속 커진다.
   BTC 2026-05-30 진입 건은 -31%(자산 기준). 알트 4개 종목에서는 자산이 0 아래로 내려갔다(MDD ≤ -100%).
3. **'SMA240 또는 SMA720' 청산(E)은 조건부 유망.** BTC 에서 CAGR·MDD·MAR 모두 좋아지고, 11개 중 9개 종목에서 MAR 이 개선됐다.
   다만 BTC 개선분은 2021~2023 에 몰려 있다 (2024~2026-08 CAGR: A 23% vs E 20%). 거래 수도 적다.
4. 원본을 포함한 모든 변형이 종목 중앙값으로는 손실이다 (CAGR -2% ~ -22%). 이 표본에서 전략이 통한 곳은 BTC 이고, SOL·AVAX·ETH 는 일부만 통했다.
